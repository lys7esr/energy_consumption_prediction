ML Model to predict the energy consumption in a day and then estimating the cost based on user's input.

SDG 7: Affordable and Clean Energy
Dataset taken from kaggle: "https://www.kaggle.com/datasets/samxsam/household-energy-consumption"

Algorithms used for comparison: Linear Regression and Random Forest, Random Forest is comparatively best model for now and is used in the streamlit application to predict the energy consumed

Run streamlit app: python -m streamlit run app.py

To run the project, run all the cells of file in sequence, 01,02,03 and then app.py i.e. streamlit application
